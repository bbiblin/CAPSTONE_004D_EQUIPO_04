# Movimap — Términos de uso del producto de datos

> Plantilla de **términos de uso / licencia** para el acceso al producto de
> datos de Movimap por parte de instituciones / municipalidades.
> **Documento modelo**: adaptar con nombre del cliente, alcance y condiciones
> comerciales antes de firmar. No constituye asesoría legal.

---

## 1. Partes

- **Movimap** (en adelante, "el Proveedor") — plataforma de reportes de
  incidencias de accesibilidad urbana.
- **[Nombre de la institución / municipalidad]** (en adelante, "el Cliente").

## 2. Objeto

El Proveedor entrega al Cliente acceso a un **producto de datos** consistente en
información geo-referenciada sobre incidencias de accesibilidad urbana en la
zona cubierta, mediante la capa analítica de Movimap (`bi.incident_daily` y
`bi.incident_reports_daily`), a través de un canal de **lectura** (rol de solo
lectura `bi_reader` sobre el session pooler, o API de exportación).

## 3. Alcance y uso permitido

- El Cliente podrá consultar y analizar los datos para fines de planificación
  urbana, accesibilidad, políticas públicas y reportes internos.
- El acceso es de **solo lectura**: no se permite modificar, eliminar ni cargar
  datos en las fuentes de Movimap.
- No se permite la **reventa**, redistribución o publicación del conjunto de
  datos (en bruto) sin autorización previa y por escrito del Proveedor.

## 4. Características de los datos

- El producto de datos se entrega **anonimizado**: no incluye datos personales
  de denunciantes, usuarios ni responsables (ver `docs/data-dictionary.md`).
- Los datos se actualizan periódicamente; la frecuencia y la forma de entrega
  se definen en el plan/suscripción contratado.

## 5. Propiedad intelectual

- Movimap conserva la titularidad de los datos y del producto de datos.
- El Cliente obtiene una licencia de uso limitada, no exclusiva, no transferible,
  según este documento y el plan contratado.

## 6. Responsabilidad y garantías

- Los datos se entregan "tal cual", con el grado de exactitud alcanzado por la
  plataforma (reportes colaborativos). Movimap no garantiza exactitud absoluta ni
  ausencia de errores.
- Movimap no será responsable por decisiones tomadas en base al dato cedido.
- El Cliente deberá usar el dato conforme a la legislación aplicable (p. ej.
  protección de datos personales y accesibilidad).

## 7. Seguridad y credenciales

- Las credenciales entregadas al Cliente son personales e intransferibles.
- El Cliente deberá custodiar y no compartir las credenciales de acceso.
- En caso de uso indebido, el Proveedor podrá suspender el acceso.

## 8. Vigencia y terminación

- La vigencia se define en el plan/suscripción contratado.
- Cualquiera de las partes puede terminar el acuerdo según lo estipulado en el
  plan; a la terminación, el Cliente dejará de usar el acceso y los datos.

## 9. Modificaciones

- El Proveedor podrá actualizar el alcance, frecuencia o estructura del producto
  de datos, informándolo al Cliente con antelación razonable.
